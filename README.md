# Kanopus Entity

Marketing site for Kanopus Entity — intelligence-led growth consulting. Four sections cover vision, values, services, and a local growth-audit form that downloads a brief (nothing is sent to a server).

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43147](http://127.0.0.1:43147).

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start Vite on port 43147 |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview the production build |

## Deploy on Vercel (from GitHub)

1. Push this repo to GitHub (or create the GitHub repo from Cursor, then push).
2. Open [vercel.com/new](https://vercel.com/new) and **Import** the GitHub repository.
3. Keep the defaults — Framework **Vite**, Build `npm run build`, Output `dist`.
4. Click **Deploy**.

`vercel.json` already sets those build settings.
